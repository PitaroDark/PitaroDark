_Role: full-stack development (design, frontend & backend)._

**[MapiPai](https://mapipai.com)** _(currently offline)_ — `NestJS` · `TypeScript` · `MongoDB` · `Three.js`

_Role: backend & database, plus frontend contributions using Three.js._

**[pitaro-bot](https://github.com/PitaroDark/pitaro-bot)** _(side project, for fun)_ — `TypeScript` · `Discord.js` · `Docker`
A self-hosted Discord music bot — streams audio from YouTube/SoundCloud with queue management, playback controls, and slash commands. Built with a hexagonal architecture and multi-arch Docker support.
